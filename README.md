# Сайт «ДЕЗЦЕНТР SANITAR» (Самара)

Статический сайт: HTML + CSS + немного JavaScript, без фреймворков. Работает на обычном хостинге с Apache и PHP.
Единственная «серверная» часть — приём заявок: `api/send.php`.

Скриншоты, Lighthouse и ручные проверки описаны в конце (раздел «Что проверено»).

---

## 1. Что где лежит

| Путь | Что это |
|---|---|
| `index.html`, `*/index.html`, `404.html` | Готовые страницы (адреса вида `/dezinsekciya/`) |
| `styles.css`, `script.js`, `fonts/`, `images/`, `video/` | Стили, скрипт, шрифты Golos Text (локально), картинки, видео работ |
| `api/send.php`, `api/config.example.php` | Приём заявок: почта + Telegram |
| `.htaccess`, `robots.txt`, `sitemap.xml` | Настройки Apache, поисковые файлы |
| `_src/` | Исходники: тексты, данные, шаблоны, сборщик. **На хостинг не заливать** (закрыт в `.htaccess`) |
| `ВОПРОСЫ_КЛИЕНТУ.md` | Что нужно уточнить у клиента + тексты для самостоятельной правки (хранится только локально, в репозиторий не попадает) |

## 2. Как выложить на хостинг

1. Заполните домен (шаг 3) и пересоберите сайт.
2. Залейте в корень сайта (`public_html`) всё, **кроме папки `_src`**: `index.html`, папки страниц, `api/`, `fonts/`, `images/`, `video/`, `styles.css`, `script.js`, `.htaccess`, `robots.txt`, `sitemap.xml`, `404.html`, `favicon.svg`, `apple-touch-icon.png`.
3. Подключите SSL-сертификат и раскомментируйте блок «HTTPS» в `.htaccess`.
4. Настройте форму (шаг 4) и отправьте тестовую заявку.
5. Добавьте сайт в Яндекс Вебмастер и Яндекс Бизнес, отправьте `sitemap.xml`.

Требования к хостингу: Apache с `mod_rewrite`/`.htaccess`, PHP 7.4+ с расширением cURL (для Telegram).
Если хостинг на nginx, перенесите правила из `.htaccess` (404-страница, кэш, закрытие `/_src/` и `api/config.php`).

## 3. Домен, реквизиты, любые тексты: как пересобрать

Все факты о компании лежат в одном файле **`_src/company.json`** (телефоны, ссылки, реквизиты, адрес, часы работы, e-mail, рейтинг, города, домен, ID Метрики).
Пустые значения на сайте отображаются жёлтыми плейсхолдерами `{{ИМЯ}}`, их легко найти и не забыть.

Нужен Node.js 18+ (один раз установить с nodejs.org):

```
node _src/build.mjs
```

Скрипт пересоздаёт все страницы, `styles.css`, `sitemap.xml`, `robots.txt` и выводит список ещё не заполненных плейсхолдеров.
Цены, отзывы, FAQ, подписи к видео и документы лежат в `_src/data.mjs`, тексты страниц — в `_src/pages-*.mjs`.
Цены подставляются во все тексты автоматически: меняйте только `PRICE` в `data.mjs`.

**Если Node.js нет**, домен можно заменить поиском: найти `{{ДОМЕН}}` → заменить на `ваш-домен.ru` во всех файлах `*.html`, `sitemap.xml`, `robots.txt` (Notepad++, VS Code: «Заменить во всех файлах»).

## 4. Форма заявок

Заявка (имя, телефон, услуга, тип объекта, адрес/район, комментарий, удобное время) отправляется на **`/api/send.php`**. Сервер:

- проверяет согласие на обработку данных, имя и телефон (11 цифр) ещё раз, независимо от браузера;
- отсекает ботов: скрытое поле-ловушка и время заполнения меньше 3 секунд;
- ограничивает 5 заявок в час с одного IP;
- отправляет письмо и дублирует в Telegram (достаточно, чтобы сработал один канал).

**Настройка.** Скопируйте `api/config.example.php` в `api/config.php` и заполните (файл закрыт от прямого доступа). Либо задайте переменные окружения:

| Параметр (`config.php`) | Переменная окружения | Что это |
|---|---|---|
| `mail_to` | `MAIL_TO` | Куда приходят заявки |
| `mail_from` | `MAIL_FROM` | Адрес отправителя (лучше ящик на вашем домене) |
| `smtp_host`, `smtp_port`, `smtp_secure`, `smtp_user`, `smtp_pass` | `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS` | SMTP (например, `smtp.yandex.ru`, порт 465, `ssl`). Пусто в `smtp_host` — письмо уйдёт через `mail()` хостинга |
| `tg_bot_token` | `TG_BOT_TOKEN` | Токен бота от @BotFather |
| `tg_chat_id` | `TG_CHAT_ID` | ID чата (узнать у @userinfobot; бот должен быть добавлен в чат и написать в него хотя бы раз) |

**Если на хостинге нет PHP:** зарегистрируйтесь на formspree.io (или getform.io), создайте форму и в `_src/company.json` замените `"formEndpoint": "/api/send.php"` на выданный адрес вида `https://formspree.io/f/xxxxxxx`, затем `node _src/build.mjs`. Проверки согласия и антиспама на стороне сервиса тогда настраиваются в нём; дублирование в Telegram — через интеграцию Formspree.

**SmartCaptcha (необязательно).** Точка подключения — форма `leadForm()` в `_src/layout.mjs` и проверка в `api/send.php` (блок «Антиспам»).

## 5. Яндекс.Метрика и цели

1. В `_src/company.json` впишите `"metrikaId": "12345678"` и запустите `node _src/build.mjs`.
2. Метрика (вебвизор включён) загружается **только после согласия** в cookie-баннере. Текст баннера и политики меняется автоматически.
3. Цели создайте в Метрике как «JavaScript-событие» с идентификаторами: `form_submit`, `phone_click`, `telegram_click`, `max_click`.
4. Ссылка на карточку компании в Яндексе — `"yandexReviewsUrl"` в `company.json` (появится кнопка «Все отзывы на Яндексе»).

## 6. Замена видео, документов, фото

- Видео: `video/work-NN.mp4` + постер `video/work-NN.webp`. Список и подписи — `VIDEOS` в `_src/data.mjs`. Ролики сжаты до 1–3 МБ, без звука. Скрипты сжатия — `_src/tools/media.js` (нужны `npm i sharp ffmpeg-static`).
- Документы: `images/docs/*.webp`, список — `DOCS` в `_src/data.mjs`.
- После правки данных запустите `node _src/build.mjs`.

## 8. Что проверено

- **Lighthouse** (мобильный режим): главная — производительность 94–96 (между замерами колеблется), доступность 100, SEO 100, лучшие практики 100; LCP 2,3 с, CLS 0. Внутренние страницы — 98 / 100 / 100 / 100, LCP 1,8 с, CLS ≈ 0. Замер локальный, без gzip и кэширования: на хостинге с `.htaccess` из комплекта ожидаемо не хуже.
- 16 страниц, адаптив 360 / 768 / 1440 px без горизонтальной прокрутки, светлая и тёмная темы, ошибок в консоли нет.
- Форма: маска телефона, валидация, блокировка без согласия, антиспам (время и ловушка), состояния «отправка → успех → ошибка».
- Аудит: один `h1` на странице, иерархия заголовков, `alt` и размеры у всех картинок, уникальные `id`, все внутренние ссылки и якоря рабочие, JSON-LD валиден, кредит студии в подвале на всех страницах.
- Контраст всех основных пар цветов ≥ 4,5:1.

## 9. Превью на GitHub Pages

Ветка `main` — исходники и «боевая» сборка (корень домена). Ветка `gh-pages` — тестовая сборка для показа клиенту: адрес `https://mihailburmasov.github.io/sanitar-samara/`, с `noindex` и `robots.txt: Disallow`.
Пересобрать превью:

```
BASE_PATH=/sanitar-samara SITE_DOMAIN=mihailburmasov.github.io/sanitar-samara NOINDEX=1 OUT_DIR=dist-pages node _src/build.mjs
```

и отправить содержимое `dist-pages/` в ветку `gh-pages`. Ограничения превью: GitHub Pages отдаёт только статику, поэтому `api/send.php` там не работает и форма показывает сообщение об ошибке с телефоном; плейсхолдеры `{{...}}` остаются видимыми. Боевой сайт нужно размещать на хостинге с PHP (шаги 2–4).
